What to borrow

Useful pieces from the legacy bot

Stake math

Its split calculation and re-price-after-select pattern are useful references for an execution adapter.

Parallel flow

It tries to select both books quickly. Our version should keep that idea but add stronger checkpoints.

Clear-on-change

If selected odds change, clear the betslips and skip. That maps directly to our verifier/filler layer.

Boundary

What this Vercel deploy does

It gives you a clean phone-friendly reference page and a GitHub fork to inspect. It does not run Selenium, open sportsbook sessions, fill real slips, or submit wagers. The production execution plan stays: Ocular card → open real book links → verify market/side/odds → fill slips → hover/focus near submit → stop.
